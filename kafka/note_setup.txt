create topic:
---------------------------------------------------
kafka-topics --bootstrap-server kafka:9092 \
  --command-config /etc/kafka/client.properties \
  --create \
  --topic demo-topic \
  --partitions 1 \
  --replication-factor 1
  
delete topic:
---------------------------------------------------
kafka-topics --bootstrap-server localhost:9092 \
  --command-config /etc/kafka/client.properties \
  --delete \
  --topic demo-topic
  
if using SASL_, auth must be included:
to create client.properties file:
cat > client.properties <<EOF
security.protocol=SASL_PLAINTEXT
sasl.mechanism=SCRAM-SHA-512
sasl.jaas.config=org.apache.kafka.common.security.scram.ScramLoginModule required username="admin" password="admin-secret";
EOF







To create user in Kafka, using SASL_ is not working.
So, it must be using PLAINTEXT for the first set up and create all required users.
When down compose not to use -v for this step because of created users.

Then update docker-compose.yml to have SASL_ for PALINTEXT.
up compose file again.


user creation script:
------------------------------------------------------
kafka-configs --bootstrap-server kafka:9092 \
  --alter \
  --add-config 'SCRAM-SHA-512=[password=admin-secret]' \
  --entity-type users \
  --entity-name admin
  
kafka-configs --bootstrap-server kafka:9092 \
  --alter \
  --add-config 'SCRAM-SHA-512=[password=app-secret]' \
  --entity-type users \
  --entity-name app


check users created:
-------------------------------------------------------
kafka-configs --bootstrap-server kafka:9092 \
  --command-config /etc/kafka/client.properties \
  --describe --entity-type users
  
  
delete user:
-------------------------------------------------------
kafka-configs --bootstrap-server kafka:9092 \
  --command-config /etc/kafka/client.properties \
  --alter \
  --delete-config 'SCRAM-SHA-512' \
  --entity-type users \
  --entity-name admin
