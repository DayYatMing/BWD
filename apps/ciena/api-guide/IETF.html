IETF

IETF Objects

IETF is an evolving standard with active regular releases to the standard.

Navigator MC supports the following IETF object types

  • Node: A IETF Node is an abstraction of a forwarding entity in the network. A IETF node can exist on different abstraction levels in the network and map to a single device or a collection of devices. In Navigator MC, a Node maps to a single physical device.

  • Link: A Link represents the unterminated transfer of information at a given layer in the network. Link connects Termination Points.

  • TerminationPoint: A TerminationPoint represents a connection point at the edge of the Node at a given layer.

Contents

IETF support in Navigator MC is disabled by default but can be enabled by your system administrator. See IETF Administration Guide for details.
